## New features

- Embed vault HTML files in Markdown notes using an `html-viewer` code block.
- Find text with highlighted matches, move between matches, and jump to document headings.
- Switch between responsive preview widths for desktop, tablet and mobile layouts.
- Inspect tracked assets, missing files, blocked resources and runtime errors in the diagnostics panel.
- Open `.htm` files as well as `.html`, and use command-palette actions for reload, source, find and print.
- Print previews or save them as PDF using the system print dialog, with document print styles preserved.
- Save script permissions per file, shared across tabs and embeds and retained when files are renamed.

## Security and reliability

- Previews now use an opaque iframe origin and a plugin-owned content security policy. Document scripts cannot access the Obsidian parent DOM or APIs.
- **Document scripts are disabled by default.** For trusted interactive HTML, enable **Run document scripts** in the preview toolbar. Remote scripts, styles, fonts and network requests remain blocked.
- Improved vault path handling, percent-encoded filenames, image `srcset`, CSS URLs and nested local CSS imports.
- Preserved stylesheet media conditions and disabled or alternate stylesheet behavior.
- Fixed stale asynchronous renders, dependency tracking across file creation, deletion and renames, and preview cleanup.
- Corrected the reported Obsidian review findings for stylesheet handling, DOM construction, message types and popout-window timers.

## Development checks

- Added the reported Obsidian lint rules and type-aware unsafe-value checks.
- Expanded unit and browser regressions for sandbox isolation, search styling, malformed commands and popout timer cleanup.
- Updated development dependencies and their security overrides.
